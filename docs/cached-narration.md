# 缓存朗读与实时问答

网页使用已有 paragraphs 作为主播讲解稿，中文不再改写。用户开始播放时才请求当前段音频，文字在该段开始播放后出现在对话区域。暂停或提问后从未完成段落的开头恢复。没有自动预生成整期。

`POST /api/speech` 接受日期、版本、段号和语言；服务端从有效早报读取正文，不能提交任意文本。首次生成保存至 `data/speech/`，同一版本、文本、语言、模型、声音重复播放复用缓存。`GET /api/speech?key=...` 只读取音频。并发生成使用文件锁；忙时提示稍后继续，不重复付费请求。

默认 TTS_MODEL=gpt-4o-mini-tts、TTS_VOICE=marin。英文通过 TRANSLATION_MODEL=gpt-5.4-mini 翻译当前段，译稿单独保存，合成失败后重试无需重新翻译。所有凭证仍仅存在服务端。

只有提问才打开原有 Realtime 会话；点击麦克风等待连接后开始录音，再次点击提交。固定播报恢复时释放 Realtime 连接。问答期间的用量沿用 `data/telemetry/voice/`。

每段音频的 JSON 元数据记录模型、声音、字符数、字节数、生成时间和英文翻译usage。MP3合成接口不返回实际token明细，ttsUsage明确为null，不能将它当成零成本。准确扣费需账户账单；首次合成收费，缓存播放不再调用模型。

自动测试使用模拟音频响应，不代表已经对真实声音音色、延迟与英文翻译质量做人工验收。
