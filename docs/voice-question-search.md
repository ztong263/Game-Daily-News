# 语音问答与联网补充

固定早报仍使用缓存合成语音；用户提问时使用 Realtime 语音回答。每次回答前显式恢复远程音频播放，避免暂停早报后连同回答一起静音。切入 Realtime 时移除固定段落的结束回调。

问答可调用 search_web。早报缺少所需事实、询问最新情况或明确要求搜索时，主播应调用此工具。后端使用 Responses web_search，默认 QUESTION_SEARCH_MODEL=gpt-5.4-mini，每次最多 3 个检索工具调用。结果交回主播口语回答，来源链接显示在对话中。检索失败应说明无法核实，不编造结果。下一轮追问可以再次搜索。

检索 tokens 和工具调用数记录在 data/telemetry/editorial.jsonl 的 question-search 阶段；Realtime 回答继续记录在 data/telemetry/voice。检索有独立费用，不能只统计语音目录。暂停或停止后，迟到的检索结果不会触发回答；已经发出的检索仍可能计费。

测试覆盖重复提问恢复播放器、同一工具事件去重、暂停后忽略结果、版本校验、来源返回、用量记录及离线禁用。自动测试使用模拟 API，不能验证用户扬声器实际听感。
